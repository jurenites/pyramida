# Block City Demo

Import `project.godot` into Godot Project Manager once, then select **Block City Demo → Run**. In its editor, F5 runs the demo.

This is a lightweight project entry inside the Pyramida repository. Relative symbolic links point to the existing Block City scripts, scenes, balance file, and shared UI/display helpers. Edit those original files as usual; there is no second source copy to synchronize. Keep this folder inside the repository.

The custom user directory matches the original Pyramida project on macOS so the demo continues to use `block_city_v2.json`. Pyramida itself retains its original startup scene.
