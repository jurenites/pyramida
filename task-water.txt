1. Voxel Basin Math: Volume to HeightIn a 2D heightmap, the lake's area is constant. In a voxel world, a basin's shape changes at every Y-level. To find the true surface level of a voxel lake, we use the Basin Fill Formula.Let $V$ be the total volume of water. Let $A(y)$ be the accessible surface area (number of empty air blocks) at height $y$. The water fills from the bottom up.The maximum filled height $Y_{surface}$ is the highest level where:$$V \ge \sum_{y=Y_{min}}^{Y_{surface}-1} A(y)$$The fractional height $H_{top}$ of the water blocks at the very top layer is:$$H_{top} = \frac{V - \sum_{y=Y_{min}}^{Y_{surface}-1} A(y)}{A(Y_{surface})}$$This allows your top layer of water blocks to render at a fractional height (like Minecraft's flowing blocks or half-slabs of water) while the blocks below are fully solid.2. To find the overflow edge (the "lip" of the basin), we need to bridge the lake system with the Flow Map we discussed earlier.

In a voxel basin, an overflow edge is defined as an adjacent Air block where the Flow Direction points outward or downward, pulling water away from the lake. If the adjacent block is just a flat plain that belongs to the same basin, the lake would simply expand its area. It only spills when it hits a block that leads downhill.

Here is the C# logic for finding these edges and converting the excess volume into falling water.

The Overflow Logic
C#
using UnityEngine;
using System.Collections.Generic;

public partial class VoxelLake
{
	// Called when remainingVolume > 0 after filling the current Y-level capacity
	private void TriggerOverflow(int overflowY, float excessVolume, VoxelGrid grid)
	{
		// 1. Find all valid escape points at the current water level
		List<Vector3Int> spillways = FindOverflowEdges(overflowY, grid);

		if (spillways.Count == 0)
		{
			// Edge case: Reached the absolute top of the world with no escape.
			// You can either delete the water, evaporate it, or flood the world ceiling.
			return;
		}

		// 2. Distribute the excess volume evenly among all spillways
		float volumePerSpillway = excessVolume / spillways.Count;

		// 3. Convert excess volume into active falling water / particles
		foreach (Vector3Int spillPoint in spillways)
		{
			SpawnFallingWater(spillPoint, volumePerSpillway, grid);
		}
		
		// 4. Update lake volume to reflect the lost water
		this.totalVolume -= excessVolume;
	}

	private List<Vector3Int> FindOverflowEdges(int overflowY, VoxelGrid grid)
	{
		List<Vector3Int> spillways = new List<Vector3Int>();

		// 4 horizontal neighbors (North, South, East, West)
		Vector3Int[] directions = {
			new Vector3Int(1, 0, 0),
			new Vector3Int(-1, 0, 0),
			new Vector3Int(0, 0, 1),
			new Vector3Int(0, 0, -1)
		};

		// Get the lake's surface blocks at the overflow Y-level
        HashSet<Vector3Int> surfaceBlocks = GetBlocksAtLevel(overflowY);

        foreach (Vector3Int block in surfaceBlocks)
        {
            foreach (Vector3Int dir in directions)
            {
                Vector3Int neighbor = block + dir;

                // We only care about boundaries that are open (Air)
                if (grid.GetBlock(neighbor) == BlockType.Air)
                {
                    // Query the Flow Map: Does this block lead somewhere lower?
                    Vector3Int flowDir = VoxelFlowField.GetFlowDirection(neighbor, grid);

                    // If flowDir is NOT zero, it means gravity pulls water away here.
					// This is our basin's lip.
					if (flowDir != Vector3Int.zero)
					{
						// Add to spillways (ensure we don't add the same block twice)
                        if (!spillways.Contains(neighbor))
                        {
                            spillways.Add(neighbor);
                        }
                    }
                }
            }
        }

        return spillways;
    }

	// Helper to filter the lake's blocks by Y-level
	private HashSet<Vector3Int> GetBlocksAtLevel(int yLevel)
	{
		HashSet<Vector3Int> blocksAtY = new HashSet<Vector3Int>();
		foreach (Vector3Int block in waterBlocks)
		{
			if (block.y == yLevel)
			{
				blocksAtY.Add(block);
			}
		}
		return blocksAtY;
	}

	private void SpawnFallingWater(Vector3Int position, float volume, VoxelGrid grid)
	{
		// Here you instantiate a dynamic water entity that travels along the Flow Map
		// until it hits a new basin, where it will add its volume to the new lake.
		WaterParticleManager.Spawn(position, volume);
	}
}
How This Behaves in Gameplay
Sheer Cliffs (Waterfalls): If the lake reaches the edge of a cliff, the adjacent block is Air, and the block below it is also Air. The VoxelFlowField returns Vector3Int.down. The code identifies this as a spillway and water falls straight down.

Gentle Slopes (Rivers): If the lake overflows onto a gradual slope, the adjacent block is Air, and the block below it is Solid, but a drop-off exists a few blocks away. The VoxelFlowField returns a horizontal vector pointing toward that drop-off. The code identifies this as a spillway, and the spawned WaterParticle will travel horizontally over the terrain until it falls.

Player Dams: If a player places a dirt block over the spillway, that neighbor is no longer BlockType.Air. The lake will automatically resume filling upward (remainingVolume continues to the next Y-level) until it finds a new, higher spillway.

public class WaterParticleManager : MonoBehaviour

    private readonly float flowSpeed = 0.25f;   // Lateral surface flow is slower

        {
            position = startPosition,
            volume = volume,
            moveCooldown = flowSpeed
        });
    }

    private void Update()
    {
        float dt = Time.deltaTime;

        // Iterate backwards because we are removing items from the list during the loop
        for (int i = activeParticles.Count - 1; i >= 0; i--)
        {
            WaterParticle p = activeParticles[i];
            p.moveCooldown -= dt;

			// Wait until it's time to move to the next block
			if (p.moveCooldown > 0) continue;

			// 1. Where does gravity/terrain pull this water?
			Vector3Int flowDir = VoxelFlowField.GetFlowDirection(p.position, grid);

			// 2. Basin reached! Water has nowhere else to flow.
			if (flowDir == Vector3Int.zero)
			{
				lakeManager.DepositWater(p.position, p.volume);
				activeParticles.RemoveAt(i);
				continue;
			}

			Vector3Int nextPosition = p.position + flowDir;

			// 3. Did we hit an existing lake mid-flow? (e.g., falling into a lake)
			if (lakeManager.IsLakeBlock(nextPosition))
			{
				lakeManager.DepositWater(nextPosition, p.volume);
				activeParticles.RemoveAt(i);
				continue;
			}

			// 4. Move the particle
			p.position = nextPosition;
			
			// Set speed based on direction
			p.isFalling = (flowDir.y < 0);
			p.moveCooldown = p.isFalling ? fallSpeed : flowSpeed;
			
			// (Optional) Update visual representation (like moving a mesh or particle effect)
			UpdateParticleVisuals(p);
		}
	}

Here is the complete C# implementation for LakeManager.DepositWater.It evaluates whether the landing position touches existing water bodies, expands single lakes, or bridges and merges multiple lakes together when water fills the gaps between them.C#using UnityEngine;
using System.Collections.Generic;
using System.Linq;

public class LakeManager : MonoBehaviour
{
    public static LakeManager Instance;

    [SerializeField] private VoxelGrid grid;

    // Fast lookup for finding which lake owns any given 3D block coordinate
    private Dictionary<Vector3Int, VoxelLake> blockToLakeMap = new Dictionary<Vector3Int, VoxelLake>();
    private List<VoxelLake> activeLakes = new List<VoxelLake>();
    
    private static readonly Vector3Int[] OrthogonalDirections = {
        new Vector3Int(1, 0, 0),  // East
        new Vector3Int(-1, 0, 0), // West
        new Vector3Int(0, 1, 0),  // Up
        new Vector3Int(0, -1, 0), // Down
        new Vector3Int(0, 0, 1),  // North
        new Vector3Int(0, 0, -1)  // South
    };

    private void Awake()
    {
        Instance = this;
    }

    public bool IsLakeBlock(Vector3Int pos)
    {
        return blockToLakeMap.ContainsKey(pos);
    }

    /// <summary>
    /// Deposits water volume at a resting position and manages lake creation/expansion/merging.
    /// </summary>
    public void DepositWater(Vector3Int position, float volume)
    {
        // 1. Direct Hit: If the position is already inside an existing lake block
        if (blockToLakeMap.TryGetValue(position, out VoxelLake existingLake))
        {
            existingLake.totalVolume += volume;
            existingLake.RebuildWaterMesh(grid);
            return;
        }

        // 2. Check for surrounding lakes (6 orthogonal directions)
        HashSet<VoxelLake> adjacentLakes = GetAdjacentLakes(position);

        if (adjacentLakes.Count == 0)
        {
            // SCENARIO A: No nearby water -> Create a brand new lake
            CreateNewLake(position, volume);
        }
        else if (adjacentLakes.Count == 1)
        {
            // SCENARIO B: Touches 1 lake -> Expand it
            VoxelLake targetLake = adjacentLakes.First();
            AddBlockToLake(targetLake, position);
            targetLake.totalVolume += volume;
            targetLake.RebuildWaterMesh(grid);
        }
        else
        {
            // SCENARIO C: Touches 2+ lakes -> Bridge and merge them into one
            VoxelLake primaryLake = SelectPrimaryLake(adjacentLakes);

            // Add the bridge block and volume to the primary lake
            AddBlockToLake(primaryLake, position);
            primaryLake.totalVolume += volume;

            // Merge all secondary lakes into the primary lake
            foreach (VoxelLake secondaryLake in adjacentLakes)
            {
                if (secondaryLake != primaryLake)
                {
                    MergeLakes(primaryLake, secondaryLake);
                }
            }

            primaryLake.RebuildWaterMesh(grid);
        }
    }

    private void CreateNewLake(Vector3Int position, float volume)
    {
        VoxelLake newLake = new VoxelLake
        {
            lakeID = System.Guid.NewGuid().GetHashCode(),
            totalVolume = volume
        };

        activeLakes.Add(newLake);
        AddBlockToLake(newLake, position);
        newLake.RebuildWaterMesh(grid);
    }

    private void AddBlockToLake(VoxelLake lake, Vector3Int position)
    {
        if (lake.waterBlocks.Add(position))
        {
            blockToLakeMap[position] = lake;

            // Track surface area capacity per Y-level
            int y = position.y;
            if (!lake.areaPerYLevel.ContainsKey(y))
            {
                lake.areaPerYLevel[y] = 0;
            }
            lake.areaPerYLevel[y]++;
        }
    }

    private HashSet<VoxelLake> GetAdjacentLakes(Vector3Int pos)
    {
        HashSet<VoxelLake> neighborLakes = new HashSet<VoxelLake>();

        foreach (Vector3Int dir in OrthogonalDirections)
        {
            Vector3Int neighborPos = pos + dir;
            if (blockToLakeMap.TryGetValue(neighborPos, out VoxelLake lake))
            {
                neighborLakes.Add(lake);
            }
        }

        return neighborLakes;
    }

    private VoxelLake SelectPrimaryLake(HashSet<VoxelLake> lakes)
    {
        // Pick the largest lake as the primary destination to minimize updates during merges
        return lakes.OrderByDescending(l => l.waterBlocks.Count).First();
    }

    private void MergeLakes(VoxelLake primary, VoxelLake secondary)
    {
        // 1. Combine total volumes
        primary.totalVolume += secondary.totalVolume;

        // 2. Transfer block ownership and update area counts
        foreach (Vector3Int block in secondary.waterBlocks)
        {
            primary.waterBlocks.Add(block);
            blockToLakeMap[block] = primary; // Retarget lookup dictionary to primary

            int y = block.y;
            if (!primary.areaPerYLevel.ContainsKey(y))
            {
                primary.areaPerYLevel[y] = 0;
            }
            primary.areaPerYLevel[y]++;
        }

        // 3. Remove secondary lake from memory
        activeLakes.Remove(secondary);
    }
}

    vec2 noise_uv = UV + vec2(TIME * distortion_speed, TIME * distortion_speed * 0.5);
    vec2 distortion = (texture(noise_texture, noise_uv).rg * 2.0 - 1.0) * distortion_scale;
    
    // Scale down distortion near the surface
    distortion *= depth_fade;

    // Sample distorted underwater scene color
    vec2 distorted_uv = SCREEN_UV + distortion;
    vec3 underwater_color = texture(SCREEN_TEXTURE, distorted_uv).rgb;

    // 3. Blend Shallow -> Deep Water
    vec4 water_tint = mix(shallow_color, deep_color, depth_fade);
    vec3 final_color = mix(underwater_color, water_tint.rgb, water_tint.a);

    // 4. Shoreline Foam Mask
    if (depth_diff > 0.0 && depth_diff < foam_thickness) {
        float foam_factor = 1.0 - (depth_diff / foam_thickness);
        final_color = mix(final_color, foam_color.rgb, step(0.5, foam_factor));
    }

    ALBEDO = final_color;
    ROUGHNESS = 0.1;
    METALLIC = 0.0;
}
