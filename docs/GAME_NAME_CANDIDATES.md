# Village and town game naming notes

Naming exploration, updated 11 November 2026. No title is selected, and choosing one is deferred. The reef is one starting scenario; a future learning scenario could use a harsher environment that is not a reef.

## Current naming direction

Prefer a name containing **Village** or **Town**. Farm and World are less appealing. Keep the identity broad enough for different environments and resources: Pearls, possible gold coins and diamonds should not define the entire game. The focus is growing a settlement. There is no pressure to settle the name now.

## Earlier candidates

| Name | Origin | Fit and tradeoff |
| --- | --- | --- |
| Pearl Culture | User suggestion | Strong double meaning: growing pearls and developing a community. Broader than farming, though the phrase also belongs to real pearl cultivation and commerce. |
| Pearl Farm | User suggestion | Immediately understandable, but implies a narrower farming game and already has a close mobile game title. |
| Reef Village | User suggestion | Warm and clear about the setting and settlement scale. Less distinctive; the phrase also appears in resort names. |
| Reef Settlement | User suggestion | Describes the activity directly, but sounds more technical and less memorable. |
| Pearlstead | Assistant suggestion | Compact combination of pearls and homestead. Suggests a lasting island home; slightly invented spelling. |
| Reef & Rafters | Assistant suggestion | Connects the reef with the visible timber architecture. Distinctive, though longer and less focused on people. |

The earlier preference for Pearl Culture or Pearlstead is superseded by the broader Village or Town direction. Reef Village can describe the starting scenario, but the final title should also fit places beyond the reef. Retain these candidates and their search findings as history, not an active recommendation.

## Preliminary name checks

Exact-phrase web searches and selected storefront searches were checked on 11 November 2026. These are preliminary discoverability checks, not confirmation of uniqueness, domain availability or trademark clearance.

- Pearl Farm has a direct near-match: [Pearl farm - play and earn on Google Play](https://play.google.com/store/apps/details?id=com.f16region.pearlfarm), an oyster and pearl farming simulator. Avoid this name if distinct game search results are a priority.
- Searches for Pearl Culture did not surface an obvious standalone game with that exact title in the returned results. Existing uses include [Pearl Culture NZ](https://www.pearlculture.co.nz/policies/privacy-policy) and the publisher name Shanghai Oriental Pearl Culture Development on [Richman 10's PlayStation listing](https://store.playstation.com/en-us/concept/10003509). The phrase is not unused.
- Reef Village appears in tourism, including the [Reef Village resort listing](https://www.7across.com/resorts/Belize/Belize/Reef-Village-Resort). No obvious exact standalone game title surfaced in the searches reviewed.
- No obvious exact game title surfaced for Reef Settlement, Pearlstead or Reef & Rafters in the searches reviewed. Pearlstead also appears in generated fantasy-name lists, so this is not a claim that the word has never been used.

## Alternatives with existing uses

- [Little Reef](https://gameanor.itch.io/little-reef) is already a game on itch.io.
- [Reeflet](https://apps.apple.com/jp/app/reeflet-%E6%B5%B7%E3%81%AE%E7%AE%B1%E5%BA%AD/id6824949327) appears as an ocean-themed app.
- [Reefward](https://www.leetdom.com/games/reefward) is already a game.
- [Reefstead](https://reefstead.com/) is used by an aquarium website.

Keep all names provisional. Choosing a title later is separate from changing the application name, icon, assets or save paths.
